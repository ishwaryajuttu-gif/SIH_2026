# BAS-HAR dashboard (React + TypeScript + Vite)

- `npm install` then `npm run dev` gives hot reload on http://localhost:5173. It proxies `/api`, `/ws` and `/video_feed` to the backend on :8000.
- `npm run build` writes `dist/`, which FastAPI serves at http://localhost:8000.

See ../README.md for the full project.
